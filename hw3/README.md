# ДЗ 3 — Датасет саммаризации товарных отзывов

Датасет для дообучения на задачу opinion summarisation: на входе набор отзывов
покупателей на один товар, на выходе — краткий вердикт и списки плюсов и минусов.
Формат chat, JSONL со строками `{"id", "topic", "messages": [system, user, assistant]}`.

| | |
|---|---|
| Источник | [AmaSum](https://github.com/abrazinskas/SelSum) (EMNLP 2021, Bražinskas et al.) |
| Лицензия | датасет — non-commercial, код источника — MIT. Подробности в [`docs/datasheet.md`](docs/datasheet.md) |
| Объём (v2) | 3981 пример, 321 товарная группа |
| Сплит | train 3185 / val 398 / test 398, разрез по группам |
| Контаминация train↔test | 0 по id, тексту, группам и near-dup парам |
| Версии | v1 — один шард источника (1996 строк), v2 — два (3981) |

Данных в репозитории нет: они версионируются DVC и лежат в локальном remote.

## Пайплайн

```
collect → clean → diversity → split
```

- **collect** — превращает сырьё AmaSum в `data/raw.jsonl` по контракту: отбирает
  отзывы, чинит таксономию, сверяет чужую разметку и выбрасывает резюме, не
  подтверждённые отзывами, разводит единственную инструкцию на 5 системных промптов.
- **clean** — валидация схемы → фильтр длин → маскирование ПДн → точная
  дедупликация → near-dup по MinHash LSH. Порядок стадий не случаен: ПДн до
  дедупликации, точная до неточной.
- **diversity** — гейт вырожденности набора: число примеров, системных промптов,
  групп, доля крупнейшей группы, разброс длин ответа. Падает, а не предупреждает.
- **split** — разрез по группам целиком плюс самопроверка на контаминацию.

Проверка контаминации существует и отдельным запускаемым гейтом —
`scripts/check_contamination.py`, возвращает 1 при любом пересечении.

## Запуск

```bash
uv sync
uv run dvc pull        # данные из локального remote
make repro             # весь пайплайн
make v1 / make v2      # переключение версии датасета
make diff              # dvc metrics diff между версиями
make diversity         # гейт разнообразия
make contamination     # гейт train/test
make check             # восемь проверок, все зелёные
```
