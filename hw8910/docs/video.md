# Одно видео 6 минут

[Открыть hw8910-demo.mp4](../../../hw8910-demo.mp4)

Локальный файл лежит рядом с папкой `mlops_hw` и архивом сдачи.
Это шестиминутная видеодемонстрация **сохранённых фактических результатов**
с русскими подписями, без озвучки. Она не выдаётся за запись рабочего стола:
команды, ответы, хеши и числа взяты из приложенных логов/JSON.
В финальном чате также дана прямая локальная ссылка на файл.

| Время | Содержание |
|---|---|
| 0:00–0:30 | Продолжение прошлых ДЗ, исходный коммит, training/eval run |
| 0:30–1:00 | Семь красных регрессий исходного кода |
| 1:00–1:30 | Зелёный CI: 51 проверка; намеренная поломка в временной копии |
| 1:30–2:00 | Prefect: сбой, Cached в новом процессе, Completed при изменении входа |
| 2:00–2:30 | Реальная оценка 50+3; 62% → 58%; отказ кандидату |
| 2:30–3:00 | Одинаковые SHA256 указателя до и после отказа; атомарная запись |
| 3:00–3:30 | Сбой между указателем и журналом; одно событие после восстановления |
| 3:30–4:00 | Реальный API, health/ready, текст, версия, токены и длительности |
| 4:00–4:30 | STUB A → B → A и фактически загруженная версия |
| 4:30–5:00 | Ошибочные запросы: HTTP 400, backend.calls не изменился |
| 5:00–5:30 | Нагрузка 8+8; throughput/latency и ожидание очереди |
| 5:30–6:00 | Ограничения и команды воспроизведения |

Воспроизвести сборку видео:

```bash
uv sync --frozen --extra model --extra video
python3 scripts/render_demo_video.py
```

Для самостоятельной живой записи по этому же плану есть `scripts/demo.sh`.
Сначала можно показать логи и `make check`, затем выполнить короткий реальный
smoke. Повторять обучение не нужно. Публикация на видеохостинг не выполнялась;
при сдаче можно приложить MP4 как файл либо загрузить его на выбранный хостинг.
