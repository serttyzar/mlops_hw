# Что изменилось относительно ДЗ 6+7 и стартера

Сохранена прежняя Git-история. Исходный прототип ДЗ 8–10 добавлен отдельным
коммитом `732ddae`. ДЗ 1–7 и их тесты не редактировались.

| Файл | Изменение и назначение |
|---|---|
| `release.py` | Content-based cache key, строгая схема/метрики, atomic write, проверка файлов |
| `lab.py` | Совместимый CLI, устойчивый кеш в workspace, schema validation JSONL, инъекции сбоев |
| `publication.py` | Write-ahead intent, идемпотентные события, восстановление указателя/журнала |
| `flow.py` | 4 задачи Prefect, persist_result, content key, новые попытки без двойного выпуска |
| `backends.py` | StubBackend и реальный Transformers/PEFT backend с общим интерфейсом |
| `service_state.py` | Снимок принятой версии, реальный прогрев, лимиты и последовательная генерация |
| `service.py` | Исправленный stdlib-адаптер для тестов без пакетов |
| `api.py` | FastAPI, lifespan, health/ready/generate, опциональный debug |
| `gate_bridge.py` | Неизменённые score/quality_gate ДЗ 6+7, пересчёт raw, привязка runtime/файлов |
| `tests_integration/` | 7 регрессий исходного прототипа + 5 проверок транзакции/артефакта |
| `scripts/` | Восстановление артефактов, полная оценка, CI/flow-опыты, HTTP-замер, упаковка |
| `metrics/`, `docs/` | Реальные ответы, manifests, отчёты, красные/зелёные логи, единый вывод |

Реальная стадия подготовки проверяет UTF-8, JSONL-схему и уникальность id.
Это не повторная токенизация и не обучение. Её вход — настоящий golden set;
результат — малый дескриптор с хешем и числом строк. Чтение training artifact
и готового eval не называется обучением.

`tests/test_release.py` из стартера и `hw67/tests/` побайтно сохранены.
