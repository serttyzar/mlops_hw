# Что изменено относительно hw67-broken

| Файл | Изменение | Зачем |
|---|---|---|
| src/sweep.py | По одному nested run на конфигурацию; весь provenance без фильтра data_* | Отдельные параметры, кривые, артефакты и версии train/val |
| src/promote.py | gate() до любой записи в реестр | Запрет регистрации при непройденном loss-пороге |
| compose.yaml | Именованный volume artifacts:/mlartifacts | Веса переживают замену контейнера |
| evaluation/solution.py | Реальные score() и quality_gate() | Строгий формат, counts, срезы и запрет регрессии |
| params.yaml | Точная HF-ревизия; тема AmaSum; registry candidate | Продолжение ДЗ 4–5 без случайного выпуска в champion |
| evaluation/params.json | Одинаковый протокол проверки фактов; критические срезы | Проверка исходной темы отзывов вместо примера географии |
| Makefile | Собственное имя реестра и промпты отзывов | Рабочие команды демонстрации |
| .python-version, .dockerignore | Python 3.12; минимальный Docker build context | Совместимость и отсутствие тяжёлых файлов в сборке |
| .dvc/, data/*.dvc, .gitignore | DVC-версии eval и тензоров; Git хранит указатели | Воспроизводимость без весов и данных в Git |
| scripts/prepare_eval.py | 50 отдельных вопросов, 3 behavioral, полный train-index | Собственный набор оценки и прозрачная разметка |
| scripts/verify_lineage.py | Полная повторная токенизация и сравнение .pt | Доказанная связь индекса train с обучающими данными |
| scripts/build_report.py | Общий вывод, таблица и график из настоящих runs | Числа не переписываются вручную |
| docs/* | Исправления, протокол, ручная проверка gold, вывод, видео | Готовые материалы для защиты |
