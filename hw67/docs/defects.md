# Четыре дефекта экспериментов

## 1. Шесть конфигураций смешивались в одном run

В src/sweep.py дочерний `all-candidates` открывался снаружи цикла. Поэтому
параметры записывались только от первой конфигурации, а следующие кривые и
артефакты попадали в тот же run. Перенесён `start_run(nested=True)` внутрь
цикла, имя run = имя кандидата. Один родитель объединяет шесть независимых
дочерних runs. Численное подтверждение — docs/comparison.csv и проверка 1.

## 2. Контейнер терял файлы моделей

PostgreSQL имел volume, а `/mlartifacts` — нет. После замены контейнера
метаданные оставались, но загрузка весов ломалась. В compose.yaml подключён
именованный volume `artifacts:/mlartifacts`. Проверка tests/check_storage.py
реально пересоздаёт только MLflow, затем сравнивает SHA256 загруженного файла.
Доказательство сохраняется в metrics/storage-check.json и комплекте сдачи.
`docker compose down` сохраняет volumes; `down -v` удаляет их и не нужен.

## 3. Из runs выкидывались версии данных

provenance() вычислял SHA256 train/val, но sweep фильтровал ключи `data_*`.
Сохранён весь словарь provenance, в родителе и в каждом кандидате. Теперь
проверка select() может обнаружить устаревшие данные. Дополнительно .pt и
три eval-файла добавлены в DVC; docs/tokenization-lineage.json подтверждает
связь 3185 train / 398 val с сырыми JSONL ДЗ 4 полным пересчётом токенов.

## 4. Регистрация обходила loss gate

promote() вычислял отношение final/base, но не вызывал существующую gate().
Теперь `ratio = gate(run, threshold)` выполняется до register_model(), тегов
и alias. Нулевой порог обязан отклонить положительный loss без записи в реестр
(проверка 6). Основной порог заранее равен 1.0, обучение — 6 × 4 шага.

## Оценка ответов и дополнительные изменения

В evaluation/solution.py реализованы score() и quality_gate(): строгий JSON
с одним ключом, соответствие id, ошибки в знаменателе, counts по срезам;
проверка совместимости протокола и моделей, пересчёт counts из per_item,
отказ при NaN, missing, ошибках и регрессиях; все три behavioral обязательны.
Повторяющиеся JSON-ключи тоже отклоняются, а ошибки генерации не маскируются
валидным текстом. Плохой ответ модели отличается от ошибки входного контракта.

Примеры медицины/географии заменены своей темой отзывов AmaSum. Базовая
ревизия закреплена, Python = 3.12. Добавлены подготовка gold, проверка lineage,
DVC-версии данных, сценарий видео и отчёт. `.dockerignore` исключает передачу
датасетов, весов и виртуального окружения в контекст сборки сервера.

Оригинальные файлы tests/ не менялись. Все 24 теста score/gate/pipeline
проходят; это синтетические контракты, а качество модели измеряется отдельно.
